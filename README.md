# Жемчуг · Картинки

Сервис для картинок историй и постов стоматологии «Жемчуг». Статический сайт: всё работает в браузере, без сервера и без ИИ.

- `index.html` — весь сервис: шаблоны постов и историй (свободное время, акция, врач, совет, прайс), обложка и аватар группы, готовый текст поста, план на неделю.
- `GUIDE.md` — как вести группу в одном стиле.
- `bg/` — фоны 1080×1920 и 1080×1350, `thumb/` — их миниатюры.
- Выкладка: GitHub Pages, автоматически при каждом изменении в ветке `main`.
